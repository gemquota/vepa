How it works

Host phone runs the sim (unchanged physics) and
broadcasts compact binary snapshots every tick.

Guests are render-only: they replicate the stride-100
particle buffer and interpolate between snapshots.

Laws / params / spawn / DNA / preset controls send
small events to the host, applied authoritatively.

Failover: if the host disappears, the guest with the
freshest snapshot is promoted and the world continues.

Run the LAN hub

  1. build:      npm run build        (in v4/)
  2. hub:        node server/server.js
  3. open on every phone:
        http://192.168.43.1:3000   (host hotspot)
        http://vepa.local:3000     (mDNS)
  4. join the same 4-char room code.

First phone = HOST (runs the sim).
Others mirror the same world in real time.
