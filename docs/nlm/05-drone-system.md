# The Drone System: Interactive Intelligence

VEPA replaces traditional tooltips with a high-density, personality-driven help system known as the "Drone Snark Processor." The Drone acts as an in-universe supervisory intelligence, solving cognitive overload through semantic compression and narrative indexing.

## Multi-Layered Help (HELP_DB)
Every parameter in the engine is documented across four layers:
1. **Hint:** Immediate context.
2. **Explanation:** Detailed functional description.
3. **System:** How it interacts with the underlying engine logic.
4. **Advanced:** Theoretical and "lore-fact" applications for expert users.

## Drone Personality and Philosophy
The Drone is a snarky, retro-futuristic interface that provides real-time feedback. It should not feel like a UI element, but like a handler or a lore entity.

### Tutorial Philosophy
* **Contextual:** Appears only when relevant.
* **Reactive:** Responds to outcomes and player behavior.
* **Encouraging:** Promotes experimentation and acknowledges failure.
* **Interruptive Intelligence:** Not a constant babysitter, but a supervisor that intervenes when anomalies emerge or new systems unlock.

## Example Interaction
* **Player spawns particles:** "Good. You have successfully invented debris."
* **Particles cluster:** "Localized accretion detected. Primitive gravitational organization achieved. Most candidates accidentally create soup."
