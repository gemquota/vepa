# The Architect Codex Philosophy

The "Architect Codex" is the functional meta-layer where the simulation’s math meets its narrative logic. In a standard physics engine, you have variables; in an Architect Codex, those variables are treated as **Genomic Laws**.

## The Architect (High-Level Controller)
Refers to the UI and the user's role. The user has "God-mode" control over the 24-word memory stride, interacting with the blueprint rather than individual objects.
* **Intent-Driven Design:** Every parameter change is logged as an architectural shift.
* **Recursive Feedback:** Real-time analysis of ecosystem stability.

## The Codex (Fact-Source & Lore)
The `HELP_DB` and `constants.js` act as the Codex—the Single Source of Truth (SSoT) ensuring sync between the physics worker and the renderer.
* **Layered Knowledge:** Technical layers (System, Advanced, Theory) explain *why* phenomena occur.
* **Emergent Narrative:** Links raw data (Mutation, Efficiency) to documented phenomena like "Genetic Drift."

## Semantic Mapping
Every index in the `SharedArrayBuffer` is mapped to a factual entry. This ensures that changing a fundamental law ripples through the documentation and Drone logic automatically. It turns an N-body sandbox into a structured Engineering Manual for artificial life.
