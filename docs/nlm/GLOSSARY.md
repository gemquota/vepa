# VEPA Glossary of Terms

| Term | Definition |
| :--- | :--- |
| **Architect Codex** | The governing design philosophy where simulation variables are treated as immutable "Genomic Laws." |
| **B-4RK** | The quadcopter Drone unit that serves as the user's primary supervisor and interface layer. |
| **Conductivity** | The ability of particles to transfer signal state through physical contact. |
| **Lattice Lock** | A state where high stiffness and low kinetic energy lead to a near-perfect crystalline arrangement. |
| **Roche Limit** | The minimum distance to a high-mass entity before tidal forces overcome structural elasticity. |
| **SAB (SharedArrayBuffer)** | The zero-copy memory region used to sync physics and rendering threads. |
| **SSoT** | Single Source of Truth; the central repository for constants and parameter mapping. |
| **Topological Organism** | A structure of particles that behaves as a single, coordinated entity with emergent intelligence. |
| **VOID_CORE** | A gravitational singularity formed by runaway positive force accumulation. |
| **Voxel Manifold** | The 3D coordinate space (2000x2000x1000) where the simulation occurs. |
