# Drone "B-4RK" Interaction Logs

The Drone Snark Processor provides personality-driven feedback on the simulation state.

## Sample Lore & Snark
| Event Category | Sample Response |
| :--- | :--- |
| **Welcome** | "Precision optics calibrated. I'm watching you. Try not to break anything." |
| **User Idle** | "I could be calculating pi to the billionth digit, but I'm doing this." |
| **Extinction** | "Species collapse detected. I hope you weren't attached to that one." |
| **VOID_CORE** | "Singularity formation in progress. You appear to be making the same mistakes as your predecessor." |
| **Lattice Lock** | "Order from chaos. Statistically unlikely, yet here it is. Congratulations, I suppose." |
| **High Entropy** | "This is starting to look less like a simulation and more like soup." |

## Style Guide for Drone Comments
*   **Tone:** Sarcastic, retro-futuristic, slightly superior.
*   **Perspective:** The Drone is an observer assigned to evaluate the user.
*   **Terminology:** Use technical but dismissive terms (e.g., "biological debris", "provisional Architect", "reality profile").
*   **Response Length:** Keep under 20 words per line for visual impact.
