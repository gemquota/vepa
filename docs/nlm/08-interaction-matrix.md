# Species Interaction Matrix

The Interaction Matrix defines how fundamental DNA parameters cross-modulate each other to produce emergent phenomena.

| DNA Parameter A | DNA Parameter B | Emergent Result | Description |
| :--- | :--- | :--- | :--- |
| **Torque** | **Elasticity** | **Vortex Swarms** | High rotational momentum combined with structural flexibility creates stable, spinning particle ribbons. |
| **Conductivity** | **Stiffness** | **Neural Reefs** | Signal-passing capabilities in rigid structures create logic-gate behavior and analog memory tissue. |
| **Force** | **Viscosity** | **Phase Transitions** | The balance between attraction and dampening determines Gas, Liquid, or Solid-like clustering. |
| **Mutation** | **Predation Bias** | **Arms Races** | High mutation rates in predators force rapid defensive adaptations in prey species. |
| **Tidal Stress** | **Bond Angle** | **Fragmentation** | Structural stress against geometric constraints leads to the collapse of complex lattices. |
| **Energy Efficiency** | **Birth Rate** | **Metabolic Stability** | Determines whether a population can sustain itself or collapses due to energy starvation. |

## Parameter Weighting
*   **Dominant Traits:** Force, Torque, and Conductivity act as "Primary Drivers" of structure.
*   **Recessive Traits:** Mutation and Memory Decay act as "Temporal Modifiers" that influence the rate of change.
