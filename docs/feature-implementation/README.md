# VEPA Feature Implementation Collection

This directory gathers the feature descriptions and implementation-planning documents that are spread across the repository's top-level guide and plan and the RRP trilogy design records.

## Purpose and source integrity

- These are collected copies of the source documents, grouped by their original role.
- The original files remain in their existing locations; this collection does not replace them.
- Feature descriptions may express planned, intended, or implemented behaviour. Inclusion here is not independent proof that a feature is complete in the current runtime.
- When assessing implementation status, verify the relevant source module and tests as well as these design records.
- Some relative links inside copied source documents refer to the original repository layout. The source path for each copy is recorded below.
